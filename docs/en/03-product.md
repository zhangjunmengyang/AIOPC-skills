# 🛠️ Product & Engineering

From requirement to deploy, by engineering stage.

---

## ⭐ Top picks

**[bmad-prd](https://www.skills.sh/bmad-code-org/bmad-method/bmad-prd)**

- *Why:* Multi-role requirement breakdown into a PRD.
- *First use:* Run it on a real requirement and output a PRD plus acceptance criteria.

**[spec-driven-development](https://www.skills.sh/addyosmani/agent-skills/spec-driven-development)**

- *Why:* Write the spec before the code.
- *First use:* Write a one-page spec for a small feature, then implement.

**[test-driven-development](https://www.skills.sh/addyosmani/agent-skills/test-driven-development)**

- *Why:* Write a failing test before the implementation.
- *First use:* Add three tests to a core function, then change the code.

**[code-review-and-quality](https://www.skills.sh/addyosmani/agent-skills/code-review-and-quality)**

- *Why:* Multi-dimensional review, not just syntax.
- *First use:* Review a real PR and rank findings by severity.
