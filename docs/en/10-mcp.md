# 🔌 MCP & Runtime

Concrete servers and runtimes. Install one, prove it on a real task, then add another.

---

## ⭐ Top picks

**[Playwright MCP](https://github.com/microsoft/playwright-mcp)**

- *Why:* Browser automation, the most general web entry point.
- *First use:* Have the agent open a page, click and screenshot.

**[Context7](https://github.com/upstash/context7)**

- *Why:* Inject current library docs to avoid stale APIs.
- *First use:* Connect it and ask for current usage of a library you use.

**[Firecrawl MCP](https://github.com/firecrawl/firecrawl-mcp-server)**

- *Why:* Scraping, crawling and deep research.
- *First use:* Scrape a competitor page for pricing and features.

**[Claude Code](https://github.com/anthropics/claude-code)**

- *Why:* Terminal agent that reads, edits and runs code.
- *First use:* Use it to change one small feature and run tests.
