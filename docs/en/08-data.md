# 🔎 Data & Research

Search, scrape, analyze and monitor.

---

## ⭐ Top picks

**[deep-research](https://github.com/199-biotechnologies/claude-deep-research-skill/blob/HEAD/SKILL.md)**

- *Why:* Citation-tracked research, not a summary.
- *First use:* Run a sourced report on one competitor.

**[firecrawl](https://github.com/firecrawl/cli/blob/HEAD/skills/firecrawl/SKILL.md)**

- *Why:* Turn web pages into structured data.
- *First use:* Scrape one competitor page for pricing and features.

**[build-dashboard](https://github.com/anthropics/knowledge-work-plugins/blob/HEAD/data/skills/build-dashboard/SKILL.md)**

- *Why:* Turn data into a dashboard people can read.
- *First use:* Build a three-chart dashboard from one CSV.

**[firecrawl-monitor](https://github.com/firecrawl/cli/blob/HEAD/skills/firecrawl-monitor/SKILL.md)**

- *Why:* Get notified when a page changes.
- *First use:* Monitor two competitor pricing pages.
