# 🔎 八、数据与研究

找资料、抓数据、做分析、盯变化。

---

## ⭐ 先试这几个

**[deep-research](https://www.skills.sh/199-biotechnologies/claude-deep-research-skill/deep-research)**

- *为什么:* 带引用的深度研究，不是泛泛总结。
- *第一次怎么用:* 选一个竞品，跑一份带来源的报告。

**[firecrawl](https://www.skills.sh/firecrawl/cli/firecrawl)**

- *为什么:* 把网页变成结构化数据。
- *第一次怎么用:* 抓一个竞品页，提取定价和功能。

**[build-dashboard](https://www.skills.sh/anthropics/knowledge-work-plugins/build-dashboard)**

- *为什么:* 把数据变成可看的看板。
- *第一次怎么用:* 用一份 CSV 建一个 3 图看板。

**[firecrawl-monitor](https://www.skills.sh/firecrawl/cli/firecrawl-monitor)**

- *为什么:* 竞品/页面变化自动提醒。
- *第一次怎么用:* 监控 2 个竞品定价页。
