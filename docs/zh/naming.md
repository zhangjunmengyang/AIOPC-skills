# 🏷️ 取名与命名

品牌名、App 名、域名、商品名：中文和英文都涉及语义、发音、记忆、商标、域名和平台可用性。

---

## 命名的 7 个检查维度

| 维度 | 要问什么 |
|---|---|
| 语义 | 名字是否传达定位，而不是自嗨 |
| 发音 | 中文/英文读起来是否顺口，是否容易被听错 |
| 记忆 | 拼写和长度是否容易记住 |
| 国际化 | 目标市场是否有歧义、禁忌或难发音 |
| 商标 | 是否已被注册，类别是否冲突 |
| 域名 | .com/目标市场域名和社媒 handle 是否可用 |
| 平台 | App Store/应用市场/搜索是否已被占用 |
