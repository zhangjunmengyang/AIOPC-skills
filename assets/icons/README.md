# Navigation icons

Unmodified SVG files from [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons), retrieved on 2026-11-11. The selected icons are covered by the bundled [ISC license](LICENSE).

- `layers.svg`: skills by function
- `panels-top-left.svg`: platforms
- `workflow.svg`: business operations
- `book-open.svg`: founder collections
- `library-big.svg`: extended catalog

Used as decorative images alongside text labels. These files contain no scripts, external dependencies or emoji.
